# 60题配对评测报告：纯RAG（SimpleRAG） vs Agent（dx_agent）

> 同一题分别调用两条管道；检索证据经 hook 捕获（不改业务代码）；评分全部为客观公式，无人工打分。

> 样本：A组（原30题）+ B组（新增30题，2026-09对照向量库定稿）；完成 60+60 题次；限流重试 0 次

## 评分标准（客观公式）

| 维度 | 公式 |
|---|---|
| 召回率 | expected_keywords 出现在**检索上下文**的比例（检索层：证据找齐了吗） |
| 完整性 | expected_keywords 出现在**最终答案**的比例（答案层：要点覆盖了几个） |
| 幻觉控制 | 100 − 50×幻觉点；幻觉点 = anti_keyword 与所问档位同句出现（张冠李戴）+ 答案中无出处数字（计算题豁免），每题上限2点 |
| 准确率 | 完整性 × (1 − 幻觉点/2) |
| 检索耗时 | t≤3s→100；t≥15s→0；中间线性 100×(15−t)/12 |
| 综合 | 五维等权平均 |

### 已知评分局限（诚实声明）

1. **题17（CRM流程）**：A组历史关键词（菜单/客户信息/保存）与现库措辞（导购/标识/受理岗）脱节，两管道同罚，属题库遗留缺陷，不影响配对结论
2. **计算题豁免**：参考答案含'='的题不做无出处数字检测（算术得数不是幻觉），此类题的幻觉分仅由 anti_keyword 覆盖
3. **B管道嵌入缓存**：对比路径的分层子查询会命中进程内 embedding 缓存，检索耗时可低至毫秒级，属真实运行时特性
4. **关键词判定**：keyword 命中是'必要非充分'信号——答对关键词不代表语义完全正确，答漏关键词可能只是换了等价表述
