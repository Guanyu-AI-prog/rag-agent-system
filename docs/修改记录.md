## 修改2：Rerank请求限速

**日期**：2026-06-10
**触发原因**：第2次评测429错误74次，多跳推理通过率暴跌至20%
**评测结果**：通过率 53.3% → 66.7%（+13.4%）

### 修改文件

`workflow_langchain.py`

### 修改内容

**1. 添加import**

```diff
  from config import Config
  import requests
+ import time
```

**2. rerank调用前加限速**

```diff
  for attempt in range(Config.RERANK_MAX_RETRIES):
      try:
+         time.sleep(1)  # 限速：避免触发429
          response = requests.post(url, headers=headers, json=payload, timeout=Config.RERANK_TIMEOUT)
```

### 效果

| 题型 | 修改前 | 修改后 | 变化 |
|------|--------|--------|------|
| 场景型 | 40% | 80% | ✅ +40% |
| 边界/异常 | 67% | 83% | ✅ +16% |
| 多跳推理 | 20% | 60% | ✅ 恢复 |

## 修改3：增大Token和迭代次数

**日期**：2026-06-10
**触发原因**：第3次评测流程型仅25%，#8对比型因"Agent stopped due to max iterations"失败
**评测结果**：通过率 66.7%（持平，但题型分布改善）

### 修改文件

`.env`

### 修改内容

```diff
  # LLM模型配置
  LLM_MODEL=mimo-v2-flash
  LLM_TEMPERATURE=0.3
- LLM_MAX_TOKENS=500
+ LLM_MAX_TOKENS=1024

+ # Agent配置
+ AGENT_MAX_ITERATIONS=8
+ AGENT_MAX_TOKENS=1536
```

### 配置说明

| 配置项 | 旧值 | 新值 | 作用 |
|--------|------|------|------|
| `LLM_MAX_TOKENS` | 500 | 1024 | RAG生成的回答更完整，减少截断 |
| `AGENT_MAX_ITERATIONS` | 5 | 8 | Agent可调用更多工具，解决对比型超限 |
| `AGENT_MAX_TOKENS` | 1024 | 1536 | Agent单步输出更详细 |

### 效果

| 题型 | 修改前 | 修改后 | 变化 |
|------|--------|--------|------|
| 流程型 | 25% | 50% | ✅ 翻倍 |
| 边界/异常 | 83% | 100% | ✅ 满分 |

### 副作用

429错误从210次增至283次，因迭代次数增加导致总API调用量增大。
