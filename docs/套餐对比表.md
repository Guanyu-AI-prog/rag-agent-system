## 📊 方案对比总结

### 全额预存 vs 橙分期核心差异

| 对比维度 | 全额预存 | 橙分期 |
|----------|----------|--------|
| 优惠方式 | 每月返还话费，实付更低 | 一次性购机补贴 |
| 实付月租 | 较低（如59套餐实付39元） | 原价（如59套餐实付59元） |
| 合约期 | 24或36个月可选 | 通常36个月 |
| 购机补贴 | 无 | 有（720-2880元不等） |
| 宽带权益 | 相同 | 相同 |
| 互斥规则 | 二选一，不可叠加 | 二选一，不可叠加 |

### 各套餐特色

1. **59套餐**：入门级，无宽带，最高60GB流量+600分钟通话
2. **99套餐**：性价比之选，100M宽带可选，最高90GB流量+800分钟
3. **129套餐**：主流选择，300M宽带，最高110GB流量+1300分钟
4. **199套餐**：高速宽带，1000M可选，最高160GB流量+1800分钟
5. **299套餐**：旗舰套餐，180GB固定流量+2300分钟，1000M宽带

### 选择建议
- **预算有限** → 59套餐全额预存（实付39元/月）
- **家庭使用** → 129套餐（多副卡、300M宽带）
- **高速需求** → 199套餐（1000M宽带、大流量）
- **购机需求** → 橙分期方案（获取购机补贴）
