## 待解决问题

1. **429限流是最大瓶颈** — SiliconFlow Rerank API速率限制，迭代越多越严重
2. **对比型停滞50%** — 对比查询策略需优化，Agent工具调用轮次不足
3. **流程型仍有提升空间** — #18副卡转网、#19投诉渠道回答不完整
4. **场景型推荐能力** — #20学生推荐、#22大流量推荐缺少关键词

## 优化方向

1. 关闭rerank（`USE_RERANK=false`）— 牺牲检索质量换稳定性
2. 加大限速间隔（`time.sleep(2)`）— 牺牲速度换稳定性
3. 优化对比查询策略 — 拆分查询、结构化输出
4. 补充知识库 — 流程型文档细化
